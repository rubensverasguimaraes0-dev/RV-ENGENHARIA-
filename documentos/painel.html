0 de 3
1 Criar o banco no Supabase ~8 min

Conta nova, New project, região South America (São Paulo). Depois SQL Editor → New query, colar o instalador e clicar em Run. Ele cria as 36 tabelas, as 24 políticas de permissão, os 38 parâmetros e os 5 buckets — tudo dentro de uma transação, então roda inteiro ou não roda nada.

abrir o Supabase →
2 Virar administrador e pegar as chaves ~5 min

Authentication → Users → Add user, com Auto Confirm User marcado. Todo usuário nasce como lançador, então rode no SQL Editor update public.usuarios set perfil = 'admin' where email = 'seu@email.com'; Depois copie as três chaves em Project Settings → API.

ver o passo a passo →
3 Publicar na Vercel ~7 min

Entre com a mesma conta do GitHub, importe RV-ENGENHARIA-, cole as três chaves em Environment Variables e clique em Deploy. Não mexa em nada de build — a Vercel reconhece o Next.js sozinha, e a branch principal já está resolvida.

abrir a Vercel →

No fim do passo 3 sai um endereço parecido com rv-engenharia.vercel.app. Esse é o link do aplicativo. Abra no celular e use “Adicionar à tela de início” — ele passa a abrir como app, com ícone próprio e sem barra de navegador.

O que eu fiz enquanto você estava fora

tudo enviado ao GitHub
  • Liguei a sua logo no aplicativo inteiro
    Ela já saía nos nove documentos A4, mas não nas planilhas nem na própria interface. Agora sai nos três. O que travava era permissão: a tabela de parâmetros é só de administrador, porque guarda margem e BDI — criei uma view que expõe apenas as nove chaves de identidade, que já saem impressas em todo documento. Provei num Postgres de verdade que o lançador enxerga a logo e continua sem enxergar uma linha de custo.
  • Achei e consertei um teste que nunca rodava
    O teste de permissões do banco — o que prova o caso 25 da sua especificação — quebrava contra um banco instalado pelo instalar.sql. Passou a rodar dos dois jeitos.
  • Consertei o script de lint, que estava quebrado
    O npm run lint abria um assistente interativo e travava. Agora roda o ESLint direto. A primeira rodada apontou 9 avisos de import não usado — todos removidos, um a um.
  • Pus o instalador do banco dentro do guia
    Antes você teria que abrir 1.558 linhas de SQL no GitHub pelo celular e copiar. Agora é um botão. Conferi: copia os 65.592 caracteres byte a byte iguais ao original.
  • Corrigi um obstáculo que eu mesmo tinha inventado
    O guia dizia que você precisaria resolver a branch antes de publicar. Fui verificar no GitHub: claude/new-session-qhl3bf já é a branch principal. Não há nada a fazer ali.
  • Escrevi a carta para o Bernardo e endereçei com o nome dele
    Duas páginas em PDF, com as seis perguntas que faltam para copiar o fluxo dele — e uma saída fácil: responder por áudio no WhatsApp.
  • Pus a documentação em dia com a verdade
    O README dizia 214 testes; são 218. E o PENDENCIAS foi reescrito na ordem do que trava: publicar virou o item 1.
